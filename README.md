# 비트코인 모의매매 AI 에이전트 공개 데모

업비트 원화 마켓의 공개 시세를 조회하고 가상 자금으로 시장가·지정가 매매를 연습할 수 있습니다. 거래소 인증이나 API 키가 필요하지 않습니다. 모든 주문은 앱에서 모의 체결하고, 방문자별 임시 SQLite 계좌에 기록합니다. 기존 계좌를 연결하는 설정은 제공하지 않습니다. 세션이 끝나면 거래 내역은 영구 보관되지 않습니다.

## 로컬 실행

Python 3.10 이상에서 실행합니다.

```bash
python -m pip install -r requirements.txt
python -m streamlit run dashboard.py
```

기본 주소는 `http://127.0.0.1:8501`입니다. 업비트 공개 시세 조회에는 인터넷 연결이 필요합니다.
